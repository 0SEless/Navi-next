# P1.1 — Single Building Authoring Workflow

**Type:** Integration milestone  
**Question:** Can an administrator create a real campus end-to-end?  
**Constraint:** No new architecture. No new components unless forced. Wire what exists.

---

## Exit Criteria

P1.1 is complete when all are true:

- [x] Problems Panel visible in StudioWorkspace
- [x] Floor plan upload works and persists
- [x] Publish shows results (nodes, edges, revision)
- [ ] Room tool verified
- [ ] Hallway tool verified
- [ ] Entrance tool verified
- [ ] Stair tool verified
- [ ] Elevator tool verified
- [ ] One complete campus can be authored end-to-end
- [ ] Runtime successfully routes on published output

---

## Definition of Done

P1.1 is complete when:

- Every Exit Criterion is checked
- No workflow gate is skipped
- The administrator completes the entire workflow without touching code
- The runtime successfully navigates using only published artifacts
- No temporary workarounds remain

No "refresh the page first." No "click twice." No "ignore this warning." If there's a workaround, it isn't done.

## Gate 2 — Floor Plan

**Question:** Can an administrator upload and use a floor plan?

**Files:**
- Modify: `packages/editor/src/panels/properties/building-props.tsx` (per-floor upload UI in Building Properties)
- Modify: `packages/editor/src/graph-adapter.ts` (reverse adapter carries `floorPlanUrls` to the graph store)
- Modify: `packages/editor/src/context/create-editor-context.ts` (wire `graphAdapter.sync` on `document.changed`)
- Modify: `packages/compiler/src/artifacts/artifact-generator.ts` + `packages/compiler/src/types/index.ts` (`buildBuildingIndex` emits `floorPlanUrls`)
- Reference: `src/components/studio/legacy/MetadataPanel.tsx:182-190` (FileReader pattern)

**Done when:**

- [x] Upload control exists per floor (in Building Properties, not FloorEditor)
- [x] Image renders on canvas via existing `ImageSource` pipeline (FloorEditorCanvas reads `building.floorPlanUrls[level]`)
- [x] Floor plan survives save → reload (`GraphAdapter.sync` → graph store → localStorage)
- [x] Published output includes the floor plan (`buildBuildingIndex` emits `floorPlanUrls`)

**Design note:** The plan proposed the upload live in `FloorEditor`/`floor-props`. The existing per-building `floorPlanUrls` model (derived from `Floor.planImageId` in `toLegacyBuilding`) made Building Properties the correct home — one upload control per floor row, persisting to the same `floorPlanUrls` the floor editor and runtime already consume. Closing the publish gap (previously `buildBuildingIndex` dropped `floorPlanUrls`) was required to satisfy "Published output includes the floor plan".

**Verification (2026-07-13):** `e2e-p1.1-gate2.mjs` (headed, no auth cookie, seeded campus; localStorage seeded only when absent so reload preserves edits). Result: Floor Plans section renders per-floor Upload/Replace; after `setInputFiles` on floor 0, `__naviDebug.floorPlans` shows `b1 → [0]`; after `window.__naviSave()` + page reload, `b1 → [0]` persists (save→reload); navigating to `/studio/{id}/edit/building/b1/floor/0` shows the image (FloorEditor "No floor plan" overlay absent). pageErrors=0. Publish proven at the compiler layer: `packages/compiler/src/__tests__/floor-plan-publish.test.ts` (2 tests) asserts `buildBuildingIndex` emits `floorPlanUrls` both when the building carries `floorPlanUrls` and when derived from `Floor.planImageId`. Runtime consumption is code-verified (`src/components/map/PublicMap.tsx:277` reads `floorPlanUrls`). Editor suite: 637 pass / 1 fail (pre-existing `workflow-card` "Next:" ambiguity, unrelated to this change). Compiler suite: 81 pass. No new TypeScript errors from these changes (pre-existing `tsc` `version`/rootDir errors in `create-editor-context.ts` / `graph-adapter.ts` are structural and tolerated by Next.js/vitest).

**Capability unlocked:** An administrator can attach a floor-plan image to each floor of a building, see it immediately on the floor editor, have it persist across save/reload, and have it travel through publish into the runtime artifact.
